# Help 页面：内容、布局与设计意图

版本日期：2026-10-15。本文描述当前已实现的“首页 + 主题详情页”版本；此前双页签结构已替换。设计依据为 [Help 设计交付包](remember-me-help-design/README.md)，文字规范优先于概念图。首页 About 背景采用 [最终背景规范](remember-me-help-design-final/ABOUT_BACKGROUND_FINAL.md)。

## 1. 定位与阅读路径

Help 面向普通用户。AI 按长期指令保存和使用记忆，Web 让用户查看、理解、修正和掌握自己的积累。阅读顺序为：记忆为什么值得保存 → 如何让 AI 用起来 → 有疑问去哪里查。

侧栏保留一个 Help 入口；关闭 Debug 时仍然可用。沿用应用现有外框和侧栏，没有新增文档搜索、第二侧栏或文档专用顶栏。页面标题为“Help · 使用帮助”，副标题为“让 AI 记住你的项目和工作，下次交流不用从头解释。”

## 2. 首页布局

```text
现有侧栏           Help · 使用帮助
                  让 AI 记住你的项目和工作，下次交流不用从头解释。

                  ┌──────────────────────┬───────────────────┐
                  │ 完整品牌介绍         │ 西部世界引文      │
                  │ 记忆，是你最重要的财产。                  │
                  └──────────────────────┴───────────────────┘

                  开始使用
                  [ 连接 AI ] [ 给记忆分组 ] [ 设置记忆规则 ]

                  想了解某个功能？
                  记忆 →                    检索 →
                  统计 →                    配置 →

                  遇到问题？ 查看常见问题 →
```

首页最大宽度 1200px。品牌区采用正文与引文双栏；三张入门卡片各有序号、标题、一句说明和进入提示，整张卡片可以点击。参考区使用两列文字链接，FAQ 使用一个低视觉权重入口。

布局由 Help 的可用内容宽度决定，考虑侧栏展开和收起：不足 800px 时品牌、入门、参考和详情中的对照布局收为单列。长段正文最大宽度约 42 个中文字符，不随宽屏无限拉长。

### 品牌介绍原文

> **记忆，是你最重要的财产。**
>
> 记忆是智力的基石。我们凭借记忆理解来路、形成判断，让经历沉淀为智慧。当 AI 让知识与智能日益触手可及，你独有的经历、体验与记忆，便是你最重要的资产。
>
> Remember Me 为你保存这份积累。每一条记忆都清晰可见，可以查看、修改，也可以导出、带走。你决定留下什么，也决定交给谁使用。
>
> 昨天是 Codex，今天是 Claude Code，明天或许是 DeepSeek Harness。工具可以随时更换，你的积累与记忆，始终属于你。

正文下方是独立的引文区域：

> “你的记忆，编织成了你的自我。”
>
> “Your memories are woven into your identity.”
>
> — Robert Ford，HBO《西部世界》第一季第 9 集 *The Well-Tempered Clavier*（中文意译） · [台词出处](https://www.springfieldspringfield.co.uk/view_episode_scripts.php?episode=s01e09&tv-show=westworld-2016)

**设计意图：**先从人的经历与判断谈记忆的价值，再以可见、可修改、可导出说明用户的自主权。最后用工具更迭与记忆延续收束，保持既有完整思想递进。引文标明中文意译、英文原文、角色和剧集出处。

## 3. 主题详情页

所有详情沿用主工作区，顶部为“Help / 当前主题”面包屑。正文最大容器宽度 1000px；较长主题提供简短的页内目录。

| 路径 | 页面 | 当前内容与设计意图 |
| --- | --- | --- |
| `#help/connect` | 连接你的 AI | 复制地址 → 按 AI 提示配置 → 读取实际记忆数量。突出动态 `/read-me` URL 和“复制地址”；完整请求为折叠的次级选项。保留启动与排错说明。 |
| `#help/namespace` | 给记忆起个分组名 | 将 Namespace 解释为分组名，以“网站改版”为例说明同项目跨 AI 复用、不同项目分组、首次确认和非权限隔离边界。 |
| `#help/rules` | 让 AI 记住使用规则 | 强调保存为项目长期指令；提供组合复制、查看保存请求、单独复制规则及五个工具的手动说明。 |
| `#help/memory` | 记忆 · Memory | 先说明 AI 生成与 Web 管理的分工，用“网站改版采用暖色与大字号”教学示例解释字段，再说明查看修正和组织筛选。手动新建作为补充。 |
| `#help/retrieval` | 检索 · Retrieval | Semantic / Lexical / Anchor 三列对照，窄屏单列；介绍搜索、清除、Advanced、日期及其他筛选和无结果处理。 |
| `#help/stats` | 统计 · Stats | Memory 与 LLM Retrieval 两节，解释实际指标与适用范围，不复制仪表盘。 |
| `#help/configuration` | 配置 · Configuration | Settings / Maintenance / Danger Zone 三节，说明生效时机、数据传输、备份、服务控制与操作后果。只读，不提供执行控件。 |
| `#help/troubleshooting` | 常见问题 | 按连接与设置、记忆与检索、服务与配置组织折叠问答，包含搜索无结果、模型未就绪和下载失败。 |

### 连接地址与接入请求

地址来自当前页面的实际协议、主机和端口。Help 只交给 AI `/read-me` 说明地址，由 AI 据此选择适合自己的传输；不统一指定 `/mcp`。页面说明 `/read-me` 不是 MCP 端点，且本机地址未必能被另一台机器、容器或云端 AI 访问。

完整接入请求：

```text
请读取 <当前服务的完整 /read-me 地址>，按其中的接入指引选择当前 AI 工具支持的连接方式，帮我连接已独立运行的 Remember Me，保留已有配置，避免重复连接。需要我操作时，逐步告诉我怎么做；完成后读取记忆数量验证。若不支持或连接失败，请说明原因。
```

### 长期规则

主按钮“复制保存请求（含记忆规则）”一次复制以下请求与完整八条规则：

```text
请把下面的记忆规则保存为当前工作项目的长期指令。找到当前 AI 工具会加载的指令文件，没有就创建；保留原文，合并重复规则。分组名未填写时先问我，不要设为所有项目的默认值。完成后告诉我文件完整路径和生效步骤；无法保存时，说明原因并给出手动操作方法。
```

```text
使用 Remember Me 管理项目长期记忆。Namespace：<项目 Namespace>。未指定 Namespace 时先询问，不擅自设置跨项目默认值。

1. 主动回忆：在理解问题、分析方案和执行任务时，自然联想相关记忆；信息不足时，尝试不同线索继续检索，必要时读取全文。找到足够依据或继续检索已无明显价值时停止，不编造历史信息。
2. 复用经验：需要探索环境、寻找操作方法或反复尝试前，先回忆是否存在已有做法，核实后优先复用。下一步方法明确可靠时无需机械检索。
3. 决策与行动：重要决策前回忆历史经验、既有约束和失败教训；执行提交、部署、删除等关键操作前，检查相关的长期行为规则（如 action-rule），即使操作方法已经明确。
4. 主动积累：用户明确要求记住或长期沿用的信息应及时保存。工作中发现重要决策、经验、解决方案或可复用知识时主动保存；阶段结束或上下文压缩前检查是否遗漏。单纯要求总结不等于要求持久保存。
5. 提炼知识：以独立知识点组织记忆，保存有价值的事件、知识和抽象原则，必要时引用相关记忆 ID。区分事实、推测和待验证结论，注明依据与适用范围，避免过度泛化。自行归纳的长期行为规则须经用户确认后保存。
6. 去重与演进：写入前检索已有记忆，判断新增、更新或跳过。保留有独立价值的事件，合并重复知识，持续完善已有原则；修正过时或错误结论时保留必要的原因与证据。
7. 组织与反馈：保存、检索时使用本项目 Namespace，不擅自跨项目混写。合理填写 Categories、Keywords 和 Anchors，优先复用合适的现有分类。实际使用或评估检索结果后，通过 report 如实评价有用程度；无法判断时不强求评分。
8. 事实与安全：以当前事实和用户明确指令为准，核实记忆的适用性，遇到重要冲突时说明。不保存密码、密钥或无关隐私；删除、清空或覆盖记忆前取得明确授权。工具失败时如实说明，不声称未完成的操作已经成功。
```


手动说明保留 Claude Code、Codex、OpenCode、DeepSeek Harness 和豆包五项及原有官方链接；用户按需展开。明确分组名替换、完整文件路径、纯文本文件及避免 `.md.txt` 等操作细节。

### 功能说明中的准确性

- 新建记忆摘要留空时可从正文生成；编辑时明确清空摘要会保存为空。
- 教学记忆示例是静态内容，明确标注，不读取或写入用户记录。
- 字段解释覆盖 Summary、Content、Namespace、Categories、Keywords、Anchors；分类最多 3 项，标识最多 5 项。
- 同维度多个筛选满足任意一个，不同维度同时满足；日期依据更新时间，同时作用于浏览与检索。
- Lexical 的连续中文匹配有限，Anchor 只查已保存标识；不同模式的分数不可直接比较。
- Memory 解释总量、分组分布、Top N、Unique Count 和 Coverage；LLM Retrieval 解释检索次数、时间分布、模式、获评分检索、反馈覆盖率和结果评分。
- Feedback Coverage 的分母是有结果的检索次数，不是所有检索；它不是准确率。Average Rating 对有效结果评分项取平均。正数、零、负数分别对应 Positive、Neutral、Negative。
- Settings 明确主题立即生效、Debug 保存刷新、端口与本机访问限制保存重启、语言仅保存偏好、下载与代理在后续模型准备中使用。
- Maintenance 明确浏览页签不等于进入维护，结束后需要手动退出；区分 Import 导入新记录和 Recover 覆盖全部记忆，说明同步及完整备份需要相应存储能力。
- Help 没有配置表单或执行危险操作的按钮，用户到侧栏配置页操作。

## 4. 导航、复制与可访问性

首页地址为 `#help`。详情页使用上表路径，保留 URL 中原有查询参数。未知 Help 路径归一化为首页。页内目录只滚动和移动焦点，不改主题地址。

点击侧栏 Help 始终进入首页；面包屑返回首页恢复此前入口焦点与首页滚动位置。进入详情聚焦标题、滚动到顶部。隐藏主题从布局和键盘顺序中移除。

浏览器后退、前进支持 Help 内部及与其他应用模块之间的切换；刷新恢复合法 Help 深链接。其他模块没有新增公开 URL，刷新非 Help 地址保持原有默认页面行为。模型未就绪时保留配置页启动优先级。

历史导航与普通页面切换共用记忆编辑离开保护。浏览器返回时先恢复当前历史位置，再询问是否放弃草稿：取消保留页面、地址和编辑内容；确认后继续原来的历史跳转，不添加重复记录。

可复制内容有四类：地址、接入请求、保存请求与规则组合、规则单独文本。成功显示反馈；失败时提示手动复制，并展开相关原文。外部说明链接在新标签页打开。

所有链接、按钮和折叠标题有键盘焦点样式；主要点击区域至少高 44px。页面使用语义标题、面包屑、原生折叠控件和关联的可访问性标签。

## 5. 视觉规则

| 元素 | 当前规则 |
| --- | --- |
| 页面外框 | 复用现有 Shell、Sidebar 与主题变量 |
| 阅读容器 | 首页 1200px、详情 1000px；正文 14px、行高 1.8 |
| 页面标题 | 26px，窄内容区 24px |
| 品牌主张 | 28px，窄内容区 24px / 22px；尽量避免拆开“最重要的财产” |
| 品牌区域 | Light/Dark 抽象波纹背景、细边框、正文与引文双栏；背景左淡右强，仅用于首页 About |
| 引文 | 细竖线、中文 20px / 窄屏 18px、英文 13px、出处 12px |
| 入门卡片 | 三列、少量序号，无重复装饰图标 |
| 参考入口 | 两列文字链接与细分隔线，不做第二组仪表盘卡片 |
| 详情正文 | 单个阅读表面，局部使用示例、术语列表及对照布局 |
| 警示 | 仅危险操作说明使用细红线和标题强调 |
| 响应式 | 以实际内容宽度 800px 为多列边界，420px 以下进一步缩小内边距；明暗主题共用布局 |
