# Remember Me — Help UI 设计交付包

2026-10-14 · 内容结构已在讨论中确认；本包为设计与实施指导，**没有修改代码**。

## 文件

- `HELP_DESIGN.md`：产品定位、内容架构、布局、交互、Light/Dark 视觉规范。
- `HELP_CONTENT.md`：首页与各详情页的中文文案、示例和必要术语、FAQ。
- `HELP_IMPLEMENTATION.md`：Codex 分阶段实施计划、边界及验收清单。
- `mockups/`：四张 Light/Dark 概念参考图（首页、Connect AI、Memory、Configuration）。注意图片存在生成式偏差，不能直接照图实现。

## 使用方式

把本包交给 Codex，先要求其执行 `HELP_IMPLEMENTATION.md` **阶段 A 的只读核对**，确认实际代码与文案一致，再明确授权后续修改。

## 一句话原则

**让 Agent 负责记忆，让用户掌握记忆；Help 只解释必要内容，不做企业级文档门户。**
