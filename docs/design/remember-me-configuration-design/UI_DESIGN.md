# Configuration — UI Design Specification

## 1. 定位与结构
在同一「配置」页面中使用两个同尺寸、固定位置的 Tab：**常规设置（Settings）**、**维护工具（Maintenance）**。切换 Tab 只是视图切换，绝不自动进入或退出维护。所有运维卡片在非维护状态下仍可浏览；表单可预先查看/填写，执行按钮严格门控。

全局运行状态显示在**现有 Shell 顶栏右侧**，不在本页再重复固定状态栏。跨 Memory / Retrieval / Stats / Configuration 使用一致状态显示：运行中（绿）、维护中（橙）、模型未就绪（黄）、维护异常（红）、状态不可用（灰）。悬停可显示当前动作、模型进度/错误等适合的信息；状态胶囊只读，不做切换控制。避免与 Refresh / Debug 控件碰撞。

## 2. Settings Tab
纵向两张卡片：

### Appearance
- 主题单选：跟随系统 / 浅色 / 深色。
- 立即生效，无需保存；仅保存在当前浏览器 `localStorage`，key=`remember-me.theme.v1`；「跟随系统」监听操作系统偏好变化。

### Service Configuration
- HTTP 端口：整数 1–65535，默认 1314；保存后需重启；启动参数 `--port` 优先于配置文件。
- 语言：`zh-CN` / `en`；目前仅保存偏好，**未接入实际 i18n 翻译**，不得暗示已经切换语言；现有约定提示重启后生效，但不宣称界面已经翻译。
- 仅本机服务（推荐）：选中监听 `127.0.0.1`；取消选中监听 `0.0.0.0`；保存后需重启。取消勾选立即出现红色安全警告；若本次保存将本机访问改为非本机访问，还需安全确认弹窗。
- 启用 Debug 模式：布尔配置 `debug`，默认 `false`；**不支持 `--debug` 启动参数覆盖**；保存后刷新页面生效，无需重启。控制顶部 Debug 按钮、Audit 页面及诊断入口的可见性；元素检查需从 Debug 入口开启。不要把它误解为日志级别设置。
- 缓存缺失时自动下载：`auto_download_model` 布尔值；用于下一次模型准备。
- 使用 HTTP/HTTPS 代理：`proxy.enabled`；关闭时隐藏地址输入并保留已保存凭据；开启时展开地址输入，空白表示继续使用已保存地址。绝不在输入框回填脱敏 `***@` 或真实密码；仅说明已配置和「留空保留」。无已存有效地址时开启必须填 URL。
- 服务配置共享一个「保存配置」按钮：表单有变更且合法时可点击；保存无需维护模式；**不自动重启服务**。保存成功提示是否仍有需重启生效的更改；可引导跳到 Maintenance，但不会擅自发起维护或重启。模型未就绪时，保存后前端沿用现有 `/api/model/retry` 调用尝试准备模型，显示相应状态提示。

安全提示应说明取消「仅本机服务」将对局域网开放管理页、SSE、MCP、`/api`；服务无账号密码，其他设备可能读写删除记忆、导入导出及控制服务；当前 `/mcp` 的 Host/Origin rebind 防护也会被关闭。不要以小字弱化风险。

## 3. Maintenance Tab：卡片顺序
纵向紧凑卡片，简单动作直接显示，复杂表单按需展开。页面滚动，主 Shell 顶栏保持其原有行为。无需增加第二套 sticky 状态区。

1. **Maintenance Mode**：状态、当前动作/错误、Enter/Exit 控件；未进入维护时仍可浏览其他卡片；此卡不必提供重复的全局状态胶囊。
2. **Model Management**：已就绪时紧凑；模型缺失、准备中、验证中、失败、取消中显示相应进度和错误；重试按已有特殊状态规则。
3. **Data Transfer**：Import JSONL / Export JSONL 为两个独立折叠行。
4. **Data Management**：Sync Backup 直接操作；Migrate Namespace 按需展开表单。
5. **Server**：Restart 和 Shut Down 直接展示，各需确认；Shutdown 用危险按钮，但**仍在 Server 卡片中**。
6. **Danger Zone**：最底部独立浅红轮廓卡片，包含 JSONL Recover / Clear Memories。两者都需要 8 位随机确认码。

**展开原则**：不因禁用而隐藏卡片或说明；导入/导出及迁移操作完成后不自动折叠，保留结果直到用户主动收起或离开视图。进入/退出维护均需用户明确操作，运维任务结束不自动退出维护模式。

## 4. 视觉规范
沿用已确认的 Remember Me Shell、主导航、列表页风格。专业、克制、科技感、紧凑内聚。Light / Dark 严格对应，Tab 的位置和尺寸一致，卡片的左右边界、行高、间距、按钮大小在两主题中一致。蓝色突出主要动作；常态/禁用动作灰度分层；危险动作红色细边框与文字，**不使用整块鲜红背景**。Danger Zone 无须占据过大视觉权重。文字说明应完整、简洁，不堆叠大段解释。

视觉图片仅供布局、密度、主题参考；不要按图添加未确认字段、端口、存储目录或日志配置。最终界面必须包含本文档实际字段。
