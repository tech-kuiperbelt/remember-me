## 用户确认的行为

配置页面增加“启用 Debug 模式”，效果等同启动 --debug。设置持久保存，保存后刷新页面生效，不自动刷新或重启。允许配置页关闭本次由 --debug 启用的状态；后续若仍带该参数启动，启动时重新启用。

## Coding Plan 与实现

- Configuration 新增 debug 布尔字段，默认 false，统一文件/API 类型校验和 JSONC 注释保留；旧文件缺失字段按 false 读取，不因只读加载重写文件。
- Settings.UI_DEBUG 携带配置启动快照，Runtime 持有当前 debug_effective。启动参数显式启用；未给参数时使用配置状态。保留无 Runtime 构造的显式 Debug 测试路径。
- GET/POST /api/config 及兼容 /api/config/model 返回 debug（持久值）和 debug_effective（只读有效值）。后者不可作为提交字段。请求省略 debug 不改变当前状态；显式提交时先完成校验和持久化，再改变有效值；失败保持旧状态。
- Admin HTML 每次在控制线程池读取当前有效值生成 data-ui-debug。新打开/刷新页面统一应用状态，原页面保留已有导航与模块，不增加动态挂载。
- 普通配置区开关反映有效状态并提交 debug，包含用途说明；保存状态与页面启动标记不同时展示刷新提示。开关不自动开启元素检查。
- 不影响日志级别、MCP、数据库；stdio 无 UI 效果。Restart Server 保留参数，带 --debug 重启会再次启用；不移除用户明确提供的启动参数。
