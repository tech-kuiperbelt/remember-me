# 50.8 移除独立 Keywords UI

日期：2026-10-11。状态：用户已验收并明确授权提交，定向验证通过，随本次提交归档。生产未重启。

## 用户决定与实现范围

导航移除 Keywords 菜单，独立 Keywords 页面不再保留。Memories 的关键词候选、筛选、编辑与 Stats 的关键词统计和下钻继续可用；MCP `list_keywords`、Admin `POST /api/keywords/query` 和后端存储没有改变。

- `web/index.html` 删除 `nav-keywords`、`page-keywords` 和其独立搜索/分页表单。
- `web/static/js/main.js` 删除 Keywords import、mount、页面注册和独立页跳转回调。
- 删除 `web/static/js/keywords.js`；清除 `memories.js` 只服务独立页的 `prepareKeywordBrowse` 导出包装。
- `memories-data.js` 的关键词 Browse 准备逻辑仍由 Stats metadata 下钻使用，予以保留。
- `router.switchPage('keywords')` 按现有未知路由规则返回 false，当前页不变，无跳转兼容别名。
- 导航顺序为 Memories / Stats / 配置 / Audit；Sidebar 展开/折叠及其他页面视觉保持既有实现。

## 测试适配与结果

既有测试中以 Keywords 作为普通离页目标的场景改用 Stats；独立页专属分页与搜索场景移除，关键词精确跳转改由 Stats ranking 发起。新增 `keywords-removal` 场景验证菜单/DOM/路由移除、导航顺序及保留的候选、搜索、跨页草稿和下钻。综合 Admin 脚本中旧的 `detail-namespaces` datalist 断言同时更新为现有 Namespace picker，测试覆盖不减少。

通过 8 个浏览器场景：

- `keywords-removal`
- `1280x720@1` 综合 Admin（含 filters/search/acceptance）
- `search-functional`
- `detail-functional`
- `stats-functional`
- `retrieval-functional`
- `acceptance-1440x900-light-expanded-search`
