# [45] 模型缺失时的配置入口与强制维护

2026-09-30 实现，修正 [44] 首次缺少模型时 Web 也无法启动的问题。随本次提交归档、生产未重启。

后续 [47](47-config-page-and-maintenance-actions.md) 将完整配置保存改为无需维护模式，
上方为普通配置，下方为维护操作；模型未就绪的强制维护规则保留。

## 行为

- HTTP 启动先尝试仅加载缓存；缓存缺失时开放 Web/MCP 传输，进入维护，
  `required_reason=model_not_ready`。自动下载关闭时等待操作，开启时后台准备模型。
- 未就绪时记忆读写、搜索和依赖数据库的维护操作返回 `model_not_ready`，
  后端明确拒绝退出维护。工具列表、配置页、状态、审计、重启和关机可用。
- 配置页面自动打开；可以保存 HTTP/HTTPS 代理和自动下载开关。保存后显式重试，
  先取消并等待旧任务结束，再应用新配置，仅运行一个模型任务；无需重启服务。
- 展示下载库真实字节进度，标明当前文件/下载批次；没有总量时使用不确定进度。
  加载、warmup、profile/索引校验通过后解除强制维护原因，仍需手动退出维护。
- 下载及验证失败保留配置入口和错误信息，释放已取得的业务资源及锁；可以重试。
  关机协作取消下载并等待 worker 退出，随后清理 runtime。stdio/维护 CLI 保持同步行为。

## 接口与实现

- `GET /api/maintenance` 增加强制原因及模型状态；`GET /api/model` 获取准备状态。
- `GET/POST /api/config/model` 查看/保存下载策略，写入要求维护且无其他维护动作；
  仅允许代理及自动下载字段，复用文件配置校验和原子写入，状态隐藏代理凭据。
  未传代理 URL 保留原地址，防止 UI 的脱敏地址覆盖真实凭据。
- `POST /api/model/retry` 请求准备或取消后重试；显式操作允许下载，即使自动下载关闭。
- Runtime 拥有 worker、取消事件和线程安全进度；HF/FastEmbed 的字节计数适配器只在
  单个准备任务内生效，结束恢复原库入口和 HTTP session。模型准备/配置/重试写 audit。

## 验证

547 项 pytest 通过（7 条依赖弃用提示），浏览器回归通过。

- 自动/手动准备、代理失败后配置重试、旧任务取消后串行重试、字节进度与未知总量。
- 未就绪时 Web 可访问、记忆 HTTP/MCP 拒绝、维护无法退出；完成后读可用、写仍暂停，
  手动退出后恢复写入。验证失败释放数据库锁，关机取消并清理任务。
- 实际 Hugging Face HTTP 下载流程通过模拟响应验证真实字节计数，无外部下载。
- 浏览器回归验证进度条、错误安全显示、代理保存重试、强制维护按钮及完成后的退出按钮。
- 真实 Sentence Transformers 空缓存启动独立 HTTP 服务：配置页可访问、维护退出拒绝、
  stats 返回 503，等待下载期间未创建业务数据库。未触碰生产记忆库或重启生产服务。
