## 实施

- 既有抽屉宽度、固定 Header、独立滚动、按钮顺序和动画保持。View Edit 使用主操作样式，关闭按钮降低视觉权重；读取文字及字段间距收紧，Summary 14px／500，Content 14px／1.6。Categories 淡蓝、Keywords 灰、Anchors 透明描边，详情完整展示全部标签，不再截取前五个关键词。空 Summary／标签显示 `—`，不改变存储值。
- Technical details 仍默认折叠，包含基本键值信息和只读 Raw metadata。ID 旁的复制图标具有 title／aria-label；时间显示本地 YYYY-MM-DD HH:mm:ss，tooltip 保留原始 ISO。JSON 安全地用文本节点与低饱和 token 颜色呈现，保持完整缩进及原始内容，最高 240px，支持纵向及长行横向滚动。ID／完整 JSON 复制成功显示短暂对勾，失败沿用错误反馈，无成功 Toast。
- Summary 自动在 2–5 行范围增高（64–130px），Content 在 240–500px 范围增高，超过内部滚动。Edit／Preview 使用相同高度，保留未保存文本、Markdown 规则及光标／选区／滚动恢复；宽度或字体改变后重算，销毁编辑器释放观察者。
- Create 去掉 Other metadata 输入及对应前端草稿／解析路径；创建载荷仅来自既有专用字段。Edit 更新载荷和服务端 metadata 合并逻辑不变，已有任意附加属性保持完整，Technical details 只读展示。
- Create 初次打开不展示红色校验。字段修改后失焦显示关联的就地错误，修正及时清除；保存按钮保留原有有效性／maintenance／dirty 规则。保存中显示 Saving…／Creating… 且防重复，错误保留草稿。
- 分类／关键词候选搜索框 Enter 与既有选择／新增操作共用限制及去重，阻止表单提交及 IME 误触发。Anchors Enter／Add 保留原有 NFKC、空白、大小写及 ASCII 去重规则；添加失败在锚点字段旁提示。三个关闭入口、未保存确认、安全默认焦点、背景 inert 和列表上下文保持。

应用文件：`detail.js`、`detail-editor.js`、`detail-model.js`、新增 `detail-technical.js`、局部 CSS；共享 `memory-value-picker.js` 仅补 allowCreate 模式 Enter 操作。Memory List／Search／Shell／后端实现未修改。回归更新详情、新增及卡片对详情标签的断言。
