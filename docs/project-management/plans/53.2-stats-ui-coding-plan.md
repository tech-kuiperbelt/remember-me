## 1. 范围与实际 API 映射

只调整 Stats 前端及必要的 Memories 下钻适配，不修改后端、SQL、MCP 契约或已冻结的 Shell／Card／Search／Detail 视觉。

`GET /api/stats/metadata` 的实际契约映射如下；All 不传 namespace，具体空间用 URLSearchParams 编码。

| API 数据 | 页面用途 |
| --- | --- |
| `scope.namespace` | 校验响应所属范围；null 表示 All |
| `total_memories` | Memories 总数，Coverage 与排名百分比的分母 |
| `namespace_options` | 全局 Stats Namespace 候选，包含有效但为空的默认空间 |
| `namespace_distribution` | 有记忆的空间数量及 All 分布圆环／完整列表 |
| `dimensions.{categories,keywords,anchors}.unique_count` | 三类实际使用值的去重数量 |
| `covered_memories`、`coverage_ratio` | 至少含一个条目的记忆数、比例和进度条 |
| `top[].value`、`top[].count` | 已按 Memory 数量排名的前 100 项；本地截取 5／30／100 |

排名条使用 count / total_memories，不使用排名最高项作为分母。所有用户值通过 textContent 渲染；空范围显示 0 和明确空列表。Category seeds 不作为实际使用去重量。

## 2. 模块与执行阶段

### A：数据与兼容边界（完成）

- `stats-registry.js` 保留旧 `/api/stats` 的全局 Namespace、Category、默认 Namespace 初始化及错误状态，独立于 scoped 页面数据。
- `stats.js` 保留 `loadStats()` 兼容入口，初始化、全局 Refresh、分类重试和 `onStatsChanged` 仍可调用。
- 页面只在可见时请求 metadata；请求序号及 active 状态阻止迟到响应覆盖新范围或隐藏页面。不增加后台轮询。
- 校验范围及统计结构；错误提供 Retry／All，未知空间错误可更新 Stats 自己的候选。Scoped 结果不写全局候选 registry。

### B：结构与复用渲染（完成）

- `index.html` 提供 Statistics 标题、Namespace、独立 Refresh 和内容容器。
- `stats-view.js` 负责安全 DOM 渲染：单个五指标 Overview；All 下 SVG 圆环加完整可点击 Namespace 列表；三个同级维度面板。
- 各维度有 Unique Count、Coverage 数量／比例／进度及排名值／数量／比例／条形图。
- Top 5／30／100 独立，本地切片不发请求；长排名仅列表内部滚动，最大 440px。

### C：交互与返回上下文（完成）

- `main.js` 通过路由 onShow／onHide 接入 Stats 生命周期；下钻通过 router 的 before-show 准备函数，保留抽屉未保存保护。
- `memories-data.js` 增加只准备、不请求的 `prepareMetadataDrilldown()`；Category／Keyword 为 Browse 精确筛选，Anchor 为现有 Anchor 模式。
- 下钻保留选定 Namespace，清空其他筛选、日期、查询及页码；Keyword 复用原有规范化逻辑。Anchor 保留大小写，K=10，不传 min_score。
- 用户后续澄清：Namespace 分布行也下钻 Memory List，以点击的 Namespace 执行 Browse，清空旧查询／元数据／日期／页码；返回恢复 Stats 的 All 上下文及滚动。顶部 Namespace 下拉继续筛选 Stats，本轮同步修正设计文档。
- `memories.js`／`memories-search.js` 同步 Anchor 参数草稿，避免复用旧高级参数。
- Stats 模块内保存 Namespace、三个 Top、三个列表滚动及页面滚动；返回重新取数据后恢复。切换 Top 只重置自己的滚动；切换空间重置滚动，保留 Top。整页刷新恢复 All／Top 5。

### D：响应式与主题（完成）

- `app.css` 仅新增 Stats 专属样式及局部图表变量；容器宽度 ≥1200 为三列，700–1199 两列，<700 一列。
- 窄屏圆环／Namespace 列表纵排，保留完整三个面板；长标签换行，无横向溢出。
- 明暗主题只改变颜色，结构／尺寸相同；原生 select／button、语义区域、进度说明、focus-visible 和重绘后的焦点恢复。
