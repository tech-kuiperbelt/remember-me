## 实施

- 保留现有 SVG 文档图标，显示尺寸 16px；Summary 14px／600、最多两行，Content 13px／最多两行。保留摘要回退和正文预览规则；无预览不再插入占位行。图标与文字分列，三层文字左边缘对齐，卡片不设最小高度。
- 卡片内边距／圆角／卡间距分别 16／8／8px，Summary → Content 8px、正文 → Metadata 12px。Hover 不改变背景，只轻微强调边框和阴影；Last Viewed 状态按后续反馈改为左侧短线（见下文）。箭头垂直居中；右下日期采用本地日期分量生成 YYYY-MM-DD，保留更新时间优先、创建时间回退及完整时间 tooltip。
- Namespace 普通文字、分类淡蓝标签、关键词灰色标签、Anchors 透明描边。空组隐藏；值处理沿用原逻辑，Anchors 保留大小写／顺序。
- Metadata 顺序为 Namespace → Categories → Keywords → Anchors，字段名与首标签不拆开，其余标签逐个流式换行。行高最多 24px、间隙 6px，总高度不超过 54px。搜索分数保留且不计入隐藏数。
- 移除原分类／关键词／Anchors 的固定数量上限和标签弹层。测量实际 DOM 布局，用二分查找可见标签前缀，再按最终 `+N` 的实际宽度校准，确保计数与可见标签一致。放不下的长标签及后续值完整隐藏，不裁切标签内容。唯一 `+N` 打开既有详情，只发一次请求。
- ResizeObserver 观察列表和 Metadata 的宽度，字体加载后重算，requestAnimationFrame 合并任务；每次重绘断开旧节点观察，隐藏页面跳过测量，恢复显示时重算。重算后保留 `+N` 焦点；按钮消失时回到卡片主按钮。
- 整卡主按钮保留原生 Tab／Enter／Space，箭头保留点击与 Debug 导航但退出 Tab 顺序；纯展示标签使用普通光标。列表装配移除旧弹层关闭调用。搜索／Shell／Detail／后端均未修改。

## Last Viewed 状态与验收

用户指出整圈蓝色焦点边框与 Hover 的灰色边框过于相似，认可改用不同视觉形式的计划，2026-10-09 实施：

- 左侧 2px × 24px 蓝色短线表示 Last Viewed（上次查看的记忆），不是 Selected（选中）；保留短线，不恢复原来的蓝色边框。关闭抽屉不清除，打开另一条时移动。标记按 memory ID 保存在当前页面会话的列表组件内；重渲染／分页／筛选不改变它，返回含该记录的页面时恢复，整页刷新重置，不做跨会话存储。
- Last Viewed 不受其他卡片 Hover 或 Focus 影响；Hover、Focus、Last Viewed 视觉上明确区分，也允许同时存在。用户已确认当前行为满足要求，无需进一步修改实现。
- 移除卡片 `:focus-within` 蓝色边框及原 `is-selected` 背景／整侧线。Hover 保留灰色边框／轻微阴影，主按钮及 +N 只在 `:focus-visible` 时显示键盘焦点环，焦点恢复保持。
- Detail 删除成功后通过既有 `emitMemoriesChanged` 事件携带可选 `{deletedId}`，列表仅在 ID 匹配时清除最近操作标记再刷新；原无参数调用与监听兼容，无后端变更。取消未保存导航不会触发新选择，因此不移动标记。
- 卡片功能复验通过：关闭保留、普通边框／背景、刷新、实际分页、返回页面、取消确认、切换记录、删除后清除（测试重新加入同 ID 以确认非仅隐藏）；8 项明暗布局通过，截图包含最近操作短线。专项首次因模拟 API 使用错误分页参数失败，改为实际 limit／offset 后复验通过。detail-functional、create-functional 通过，JS 语法及 diff 检查通过。
