# 50.9 Audit UI 精简与 JSON 详情抽屉

日期：2026-10-11。状态：用户已验收并明确授权提交；定向验证通过，随本次提交归档。生产未重启。

## 用户决定与范围

Audit 为 `--debug` 模式下的诊断页面。保持简洁，列表字体、字号、样式、间距、边框和阴影与已验收的 Memory 页面一致；Namespace 支持下拉与手动输入；箭头引导打开详情，正文只显示可读 JSON，开关动画与 Memory 相同。

保留既有工具筛选、条数和 Refresh 控件，不增加分页或统计。不修改后端 Audit API、日志轮转、裁剪规则或 Memory 视觉状态。

## Coding Plan 与实现

### Debug 入口与紧凑列表

- Audit 导航在 HTML 中默认隐藏，仅 Debug 启动时显示、挂载并注册路由；普通模式切入返回 false，不请求 Audit API。Debug 检查开关不影响页面启用状态。
- 列表复用 Memory 行表面、16px 内边距、8px 圆角、边框、Hover 阴影与 Focus 描边。首行工具与真实状态，次行时间、Namespace 和耗时；错误保留单行摘要，参数和返回 JSON 放入抽屉。
- 记录覆盖按钮使整行可点击，右侧箭头提示查看详情；原生按钮支持键盘激活。窄屏元信息换行。
- 请求版本防止旧筛选覆盖新结果；保留加载、空结果和失败状态，离页使在途响应失效。条数维持原逻辑：非法或小于 1 使用 200，最大 5000。

### Namespace 下拉

- `namespace-picker.js` 增加可选 ID 前缀和弹层容器，原 Memory 默认值保持不变。
- 候选来自共享 live Namespace 与当前加载 Audit 事件 Namespace 的去重排序合集；不额外扫描归档。允许自由输入历史空间，空值表示全部。
- 选择立即查询，手动输入按 Enter 查询；注册表更新不会覆盖输入，离页关闭弹层。

### JSON 抽屉

- 独立 Audit dialog，仅标题、关闭按钮与 JSON 正文；直接展示点击时 API 事件快照，不追加详情请求。
- `JSON.stringify(event, null, 2)` 经 textContent 输出；保留全部返回字段，不二次截断，长行在 JSON 内横向滚动。API 已裁剪内容不能还原。
- 复用 Memory 抽屉宽度、遮罩、阴影及内边距。新 `drawer-motion.js` 仅抽取动画：打开 240ms、关闭 200ms、原缓动、动画取消及减少动态效果支持。
- 打开聚焦关闭按钮、限制焦点和锁定背景；关闭按钮、遮罩、Esc 关闭并恢复触发位置。离页释放锁定，快速开关无残留。
- Debug 检查模式的 Esc 先退出检查，并将焦点留在当前 Audit 抽屉关闭按钮。
