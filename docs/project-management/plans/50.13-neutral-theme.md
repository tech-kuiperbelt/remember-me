# 50.13 — Neutral 岩石灰主题

状态：已实施，42 项浏览器检查通过，待用户视觉验收。用户已授权实施；未提交。

## 目标与行为

根据 `remember-me-neutral-theme` 设计交接，将 Neutral 接入现有主题系统。
外观选项为「跟随系统 / 浅色 / 岩石灰 / 深色」，默认仍跟随系统。
Neutral 是低眩光的浅色系蓝灰配色；系统明暗变化只影响 System。

- 沿用 `remember-me.theme.v1` 保存偏好，新增有效值 `neutral`。
- 首屏脚本与运行时同时识别 Neutral，刷新直接应用；实时切换保留页面、草稿、滚动和弹窗。
- Native controls 使用 `color-scheme: light`；存储不可用时仍可切换。
- 无后端、API、数据库、配置文件或默认行为迁移。

## 实施

- `theme.css` 增加 Neutral 色板；复用现有变量，新增工作区、控件边框、图标和状态颜色变量。
- `app.css` 中记忆类型图标、Stats 系列/标签/评分星形、维护/模型准备状态改为消费主题变量。Light、Dark 保留原有色值。
- 工作区采用 `#E8EDF2`、导航 `#D5DFE9`、卡片 `#F2F5F8`、主要文字 `#22334A`、强调色 `#205A9C`。
- 输入边框采用 `#74879A`，比参考稿更深；控件与静态分隔线分别处理。Muted 文字为 `#586B7F`，Placeholder 同步使用。
- Stats 主系列为深蓝、中蓝，其余为区分亮度/色相的低饱和蓝灰系列；标签和列表保留，成功/警告/错误继续使用语义色。
- Help 复用浅色背景图及已有表面色遮罩。品牌标识、布局、产品文案和功能保持原有设计。
- 沙白主题及概念图中的账户、亮度、强调色等功能不在本次范围。
