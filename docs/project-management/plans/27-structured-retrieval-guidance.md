# [27] LLM 结构化检索与分类写入引导

## 本次调整（2026-09-29）

- `add` 的 MCP 描述和 `metadata.categories` 字段说明，明确引导每条新记忆提供 1–3 个相关分类，优先复用 `stats.category_counts` 中符合含义的值。
- `update` 在修改正文时引导重新选择 1–3 个分类；仅改其他元数据时可保留原分类。该要求是 LLM 调用引导，不改变服务端对旧客户端的兼容校验。
- `search_semantic` 的描述、过滤字段说明和结果 hint，说明已知目标概念或分类时才用过滤条件缩小候选集；精确索引值优先，未命中值在同维度、同 namespace 内语义解析，`filter_resolution` 展示实际映射；探索性问题省略过滤条件。
- `search_meta` 的结果 hint 提醒其关键词和分类过滤仅做精确匹配。`/read-me` 的功能概览同步说明上述行为。
