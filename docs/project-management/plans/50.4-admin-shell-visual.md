# [50.4] 管理台 Shell 视觉调整

2026-10-01 实施、完成 review 并通过最终回归。本项承接 [50.2 桌面布局](50.2-admin-desktop-layout.md)
和 [50.3 主题基础](50.3-ui-theme-foundation.md)，依据
[UI 设计规范](../../design/UI_DESIGN.md)、[UI 实施规则](../../design/UI_IMPLEMENTATION_RULES.md)
与[风格示意图](../../design/UI.png)。

## 目标与范围

让现有管理台外壳贴近已确认的视觉方向：紧凑的顶部品牌区、清晰的全局状态与动作、密度统一的左侧导航。
保留页面、菜单顺序、路由、按钮 ID、真实服务状态、维护语义与主题切换。Memories 列表内容结构留到第三步。

## 实施内容

- 品牌文字和浏览器标题统一为 **Remember Me**；服务信息 `MCP Server` 与品牌名合并在同一行，
  字号和字重相同，以灰色和分隔点区分。
- 顶栏目标最小高度为 54px；品牌名和副标题同为 16px、600 字重，副标题用灰色区分。
  右侧仍按状态、Refresh、Debug 排列；状态显示语义色圆点和文字，真实状态及原有 `aria-describedby` 说明保持不变。
- Refresh、Debug 使用内联线性 SVG，保留原按钮 ID、文字与事件处理。
- 导航项目统一为 18px SVG 图标、约 36px 最小高度、13px 标签；当前页继续显示背景与左侧标记，
  hover 和键盘焦点仍清楚可见。菜单顺序、ID、`data-page` 和 `aria-current` 契约不变。
- 移除独立折叠按钮；菜单从导航顶部开始，不留折叠按钮占位。点击导航菜单项仍只切换页面，点击 `nav` 空白区域
  （如菜单列表下方空白处）切换侧栏。导航区域可聚焦，聚焦后按 Enter／Space 也可切换，
  并在 `aria-label` 中说明展开状态和操作方式。
- Debug 开关只更新文字节点，保留图标；Debug 高亮不改变导航布局。
- `layout.js` 为导航按钮设置稳定的可访问名称；折叠时在鼠标悬停或键盘聚焦后，通过 Shell 外的
  tooltip 显示菜单文本，并用 `aria-describedby` 关联。离开、失焦、导航滚动、窗口变化或展开侧栏时收起提示。
- 工作区在 900 CSS px 以下使用 16px 内边距；桌面默认仍为 20px，768px 以下保留原有表单换行行为。
  顶栏允许内部换行，工作区仍独立滚动。

## 验收与验证结果

- 保留菜单顺序与导航事件契约；浏览器回归检查原页面切换、真实服务状态、主题、表单保持、维护控件和弹窗行为。
- 没有独立折叠按钮；点击 nav 空白区或聚焦 nav 后按 Enter／Space 可折叠／展开；菜单项点击只切页。
  Debug 不改变 nav 布局。菜单项有可访问名称，鼠标悬停和键盘聚焦均显示提示，
  提示通过 `aria-describedby` 关联；离开或展开后提示消失。
- 隔离浏览器回归在 5 个视口 × 3 种缩放、主题桌面／窄窗口及边界场景中 **28/28 通过**；包括无页面级横向溢出断言。
- `.venv/bin/python -m pytest -q`：**710 passed**，7 条已有弃用警告。
- `node --check` 检查布局、Debug 模块和浏览器回归脚本通过；`git diff --check` 通过。
- Light Memories、Dark Memories、Dark 折叠侧栏和 768px Light 配置页截图已人工查看，保存在
  `/tmp/remember-shell-final/`，未入库。截图使用隔离服务；其中“状态不可用”来自测试服务状态。
- 未重启生产服务或部署。
