# 50.12 Help 独立页面

日期：2026-10-13；2026-10-14 更新。状态：首页与八个主题详情页已实施，待用户内容与视觉验收。

当前结构与交互见 [Help 页面设计说明](../../design/help-page.md)。下方前半部分保留双页签版本的实施历史，最新改版记录见文末。

## 目标与受众

侧栏增加常驻 Help 菜单，使用现有 Shell 中的独立页面，Debug 关闭时同样可访问。Help 面向人，介绍 Remember Me 作为 MCP 记忆服务和 Web 管理界面的用途，并指导用户让 agent 读取 `/read-me` 完成接入；`/read-me` 面向 agent，继续提供具体客户端配置及调用契约。

## 实现

`web/index.html` 增加 `nav-help` 和 `page-help`，位于 Audit 之后；`web/static/js/main.js` 注册 help 页面，沿用页面切换、编辑离开保护、选中状态与滚动重置。`help.js` 使用当前页面 origin 生成完整 `/read-me` 地址与接入请求，并通过现有 copyText/toast 提供复制及失败时手动复制提示。无新增接口、后台请求或依赖。

内容按用户要求优先介绍产品、Agent 接入、Namespace 和系统提示词，再提供 Web 使用、查找、整理、配置维护与 FAQ。推荐 bin/start.sh 独立 HTTP 服务供多个 agent 共享记忆，解释 stdio 单客户端与主库写锁限制；提供可复制的接入请求，让 Codex、OpenCode、Claude 等读取实际服务的 /read-me。跨机器/容器时需用户替换为 agent 可访问地址。

Namespace 用于区分项目和工作内容，推荐 agent 显式指定，同项目多个 agent 复用相同名称；不把 Namespace 描述为权限隔离。提示词模板保留待替换项目名，覆盖任务前检索、核实历史信息、阶段成果及压缩前保存、去重更新、元数据、检索反馈和失败处理。目录链接定位章节，FAQ 使用原生 details/summary。

`web/static/app.css` 使用 Help 专用类及既有主题变量，内容宽度最高 1000px，章节卡片、自然换行和窄屏内边距适配；不改变其他页面样式。

按用户要求，将重点和补充内容分为“接入与记忆使用”与“其他帮助”两页签，默认展示前者。两页签各有独立目录；支持左右方向键及 Home/End 切换、ARIA 选中状态和焦点管理；本次页面会话保留选择，刷新恢复默认。接入步骤中直接显示完整 /read-me URL 并提供“复制地址”，整段接入请求和系统提示词也可分别复制。

### 非 IT 用户引导与客户端例子

用户明确整页面向非 IT 初学者。介绍改为“共享记忆本”，Namespace 解释为工作分组；接入步骤默认让 AI 帮忙，独立启动与 stdio 命令放在展开说明中。给出“读取实际记忆数量”作为接入验证，不以 AI 口头声称成功为依据。

长期指令提供“复制给 AI 的保存请求（含完整规则）”，引导 AI 定位当前工作项目、保留原文件、补充规则并报告完整路径。说明仅发到聊天框不等于长期保存，项目文件夹不是 Remember Me 程序文件夹；手动时使用纯文本，避免 .md.txt。

根据官方资料（2026-10-13 查阅）提供五个可展开示例：Claude Code 的 /memory 与 CLAUDE.md；Codex 的项目 AGENTS.md；OpenCode 的 /init 与 AGENTS.md；DeepSeek Harness 默认项目指令加载；豆包单独标明普通聊天、智能体设定及外部 MCP 能力不能混为一谈，未确认其普通客户端的外部 MCP 入口。页面内各例附官方链接，不编造豆包固定菜单路径。
